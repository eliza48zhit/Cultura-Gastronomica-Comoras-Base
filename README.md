🛠️ Especificaciones Técnicas del ADN de Comoras
Este contrato documenta la transferencia de compuestos aromáticos y la densidad de caldos:

Nivel de Infusión de Vainilla (uint256): Cuantifica el uso de la vainilla como agente estructural en platos de resistencia. Este parámetro desafía el paradigma del uso de la vainilla exclusivamente en repostería, registrando su rol en la hidrólisis de proteínas complejas.

Saturación de Coco (uint256): Mide la densidad lipídica de la base de cocción. Una saturación alta permite una mejor suspensión de las especias volátiles y una textura cremosa característica de las islas.

Proteína de Crustáceo (bool): Validador técnico para identificar el uso de langosta o camarones, que requieren curvas de temperatura específicas en medios ácidos/grasos.

Sistema de Feedback: Funciones de darLike y darDislike integradas para la interacción on-chain.
